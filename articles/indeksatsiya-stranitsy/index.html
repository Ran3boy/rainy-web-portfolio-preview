Почему страницу не видно в поиске

Вы открываете страницу услуги по ссылке, а по нужной фразе поисковик показывает конкурентов. Начните с проверки самого адреса. Статус поможет решить, стоит ли искать техническую ошибку, разбираться с дублем или работать с содержанием страницы.

Запишите адрес и статус в каждой системе

Откройте страницу без авторизации. Если после перехода адрес изменился, сохраните оба URL. Запишите запрос и регион, в котором ожидали увидеть страницу. Это пригодится, если окажется, что она уже участвует в поиске.

В аккаунте с доступом к сайту найдите URL в разделе Яндекс Вебмастера «Страницы в поиске». В Google Search Console вставьте его в строку проверки URL. Выпишите статус, объяснение исключения, дату последнего обхода и выбранный основной адрес, если он указан. У двух систем эти сведения могут различаться. Справочник статусов Яндекса и проверка URL в Google.

После недавнего исправления сравните данные индекса Google с проверкой опубликованной версии. Если робот посещал сайт до правки, старые данные в отчёте ожидаемы. Успешная проверка текущей версии говорит о доступности страницы для проверки в этот момент. Решение о включении в индекс появится отдельно.

Выберите действие по статусу

Поисковику неизвестен этот URL
Проверьте, ведёт ли на него обычная ссылка из раздела сайта. Если карточку можно найти только через внутреннюю строку поиска, добавьте ссылку из соответствующей категории. Для сайта с картой страниц проверьте также точный адрес в Sitemap. Файл помогает Google обнаруживать страницы, но включение адреса в файл само по себе не гарантирует индексацию. Для чего Google использует Sitemap.
Страница перенаправляет на другой адрес
Откройте конечный адрес и сравните содержимое. Если услуга переехала на нужную страницу, проверяйте новый URL. Если все старые услуги ведут на главную, разберите соответствие адресов после переноса.
Сервер отдаёт ошибку
Откройте страницу без авторизации и посмотрите код ответа. Если нужная услуга по ошибке возвращает 404, восстановите страницу или настройте переход на её действующую замену. При повторяющейся ошибке сервера передайте разработчику адрес и время проверки.
Есть запрет на индексирование
Уточните, должна ли страница быть публичной. У страницы услуги мог сохраниться noindex от тестовой версии. Проверьте метатег и заголовок ответа. В Google запрет обхода в robots.txt может помешать роботу увидеть этот тег. Как Google обрабатывает noindex.
Поисковик считает страницу дублем
Сравните выбранный адрес и проверяемую страницу. Два адреса одного товара с разными параметрами могут вести к одной покупке. Если же это разные услуги, проверьте основной адрес в шаблоне, заголовки, описание и ссылки из каталога.

Если страница уже в индексе

Посмотрите, по каким запросам у неё были показы. Бывает, что по общей формулировке показывается раздел каталога, а по точной модели — карточка. Определите, что нужно покупателю по этому запросу. Если он сравнивает несколько вариантов, ему пригодится раздел. Если сверяет размеры конкретной модели, лучше подойдёт карточка. Для большого списка запросов это распределение удобно зафиксировать в карте запросов и страниц.

Запишите, чего не хватает выбранной странице для ответа на конкретный вопрос. Например, запрос содержит размер изделия, а на странице есть только фотография без подписи. Если показов мало, сначала соберите наблюдения за более длинный период. Позиция по одному запросу в вашем браузере не описывает весь поисковый трафик.

Проверьте результат после исправления

Запишите точный URL, прежний статус, внесённое изменение и дату публикации. Проверьте доступность исправленной версии и при необходимости отправьте адрес на повторный обход. Затем дождитесь нового посещения робота и сравните статус в индексе. Обработанная заявка на переобход сама по себе ещё не подтверждает появление в поиске. Как работает переобход в Яндексе.

Если исчез один адрес после переезда, начните с его перенаправления. Если одновременно выпали карточки целой категории, сравните их с работающей карточкой другого раздела. Расхождение в шаблоне, внутренних ссылках или доступности сервера подскажет, где искать общую причину. Передайте примеры адресов и даты вместе со снимками отчётов для технического SEO-аудита.
